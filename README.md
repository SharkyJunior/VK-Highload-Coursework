# VK-Highload-Coursework

## 1. Тема и целевая аудитория

> **Тема**: Google Photos

**Аудитория сервиса:**

- По данным Google на май 2017 года, сервис Google Photos достиг **500 млн. активных пользователей в месяц**. Кроме того, общее количество загружаемых фотографий достигло 1.2 млрд/день. [[1](https://blog.google/products-and-platforms/products/photos/google-photos-500-million-new-sharing/)]

**Функционал MVP:**

Аналог Google Photos будет иметь следующие функции:

- Авторизация
- Загрузка и скачивание фото
- Распознавание лиц на фото
- Поиск по галерее (дата, метаданные о камере, геоданные, лица в кадре)
- Возможность поделиться фото и видео
- Совместные альбомы (например, семейные)
- Уведомления при добавлении фото в совместный альбом

## 2. Расчет нагрузки

### Продуктовые метрики:

- MAU = ~500 млн [[1](https://blog.google/products-and-platforms/products/photos/google-photos-500-million-new-sharing/)]
- DAU = ~75 млн (из расчета отношения `DAU / MAU ~ 0.15`) [[2](https://www.ideaplan.io/metrics/dau-mau-ratio-stickiness)]
- Средний размер галереи: 2100 фото, 10,25 GB \* 20-30% (пользователи загружают лишь часть фото в облако в среднем) = ~3 GB [[3](https://www.smays.com/2024/03/how-many-pictures/)]
- Среднее кол-во действий пользователя в день **~14.2** (см. таблица)

| Тип действия                      | Доля DAU | Действий на активного пользователя в день | Действий на одного DAU в среднем |
| --------------------------------- | -------- | ----------------------------------------- | -------------------------------- |
| Авторизация (login / session)     | 100%     | 1.5                                       | 1.50                             |
| Загрузка фото (upload)            | 40%      | 13                                        | 5.20                             |
| Скачивание фото (download)        | 7%       | 2.5                                       | 0.18                             |
| Распознавание лиц (на новых фото) | 40%      | 13                                        | 5.20                             |
| Поиск по галерее                  | 18%      | 1.5                                       | 0.27                             |
| Шеринг (share)                    | 12%      | 3                                         | 0.36                             |
| Создание совместного альбома      | 1.5%     | 1                                         | 0.02                             |
| Добавление в совместный альбом    | 5%       | 3                                         | 0.15                             |
| Просмотр совместного альбома      | 8%       | 1.5                                       | 0.12                             |
| Получение уведомлений             | 60%      | 2                                         | 1.20                             |

> **Всего действий в день ~ 1,065 млрд.**

### Технические метрики:

- **Размер хранилища фото**: 500 млн. пользователей \* 3 GB = **_~1500 PB_**
